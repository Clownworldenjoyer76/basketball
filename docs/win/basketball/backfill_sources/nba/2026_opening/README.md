# NBA opening historical backfill (October 20-22, 2026)

16 user-supplied matchup odds rows matched to existing ESPN final-score game IDs.
The sportsbook and capture time are unspecified; prices are stored in the existing
legacy `*_dk_*` compatibility fields, but they are NOT verified DraftKings quotes.
The pregame capture time is unverified. The historical selection/reports are
retrospective reconstruction, not contemporaneously proven picks.

The ORIGINAL October 20 DRatings predictions/probabilities are retained exclusively.
October 21 supplied projected scores + win probabilities are imported. October 22
original predictions remain untouched. Existing historical locked picks are untouched.

The full-rebuild helper creates missing cleaned historical ensemble predictions with
zero historical rolling bias and preserves existing cleaned files. It never backdates
model generation timestamps.
